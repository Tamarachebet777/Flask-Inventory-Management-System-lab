Flask-Inventory-Management-System-lab

The system will allow  employees to add,edit,view and delete inventory items.It will also fetch real-time product data from an external API to supplement product details.

Project Structure
project
     app.py
     cli.py
     models.py
     README.md
     routes.py
     seed.py
     tests.py

Features
A Flask-based REST API with CRUD operations for managing inventory.
An external API integration to fetch product details by barcode or name.
A CLI-based interface to interact with the API.
Unit tests to validate functionality and interactions.
